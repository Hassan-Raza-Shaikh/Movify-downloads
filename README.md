# Movify downloads

Installers for Movify. Get the newest from **Releases** on the right:

- **Mac:** Movify-mac.dmg. Open it, drag Movify to Applications. The first time,
  right-click Movify and choose Open (it isn't signed by Apple).
- **Windows:** Movify-Setup.exe. If Windows warns you, choose More info, then Run anyway.

Movify tells you when a new version is out and can update itself.
